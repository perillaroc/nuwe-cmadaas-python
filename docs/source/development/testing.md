# 测试与动态时间

在线集成测试按运行时日期选择近期资料；固定时间只用于离线合成示例。各类资料使用不同基准时间，不能将 `2026-01-02` 等合成日期复制到真实服务请求。

| 资料类别 | 当前在线案例的基准时间 |
| --- | --- |
| 地面站点 | 本地日期前一天 00 时 |
| 地面格点及常规/GPS/Light/Ard 高空表格 | 本地日期三天前 00 时 |
| 地面与高空文件 | 本地日期两天前 00 时 |
| 模式格点、模式点、模式文件及底层 MUSIC | 本地日期三天前 06 时 |

这些时间是当前测试案例的选择规则，服务仍须对所选资料、时次和账号开放访问；无数据或权限失败不能当作测试通过。最新时次查询使用相对时间参数，文件下载不能把最新时次表格当成文件。

完整的配置、profile、逐案例运行方式及下载上限见仓库的 `tests/integration/README.md`。离线单元测试使用 `uv run pytest tests --disable-socket --strict-markers -q`；文档构建命令和可执行页面约定见仓库的 `docs/README.md`。
