数据对象与输出契约
==================

状态
----

已接受（2026-09-15）。

响应容器
--------

响应对象始终提供可安全检查的空容器：表格数据使用 ``(0, 0)`` 的 NumPy 数组和空列名，数值格点数据及风场分量使用 ``(0, 0)`` 的浮点数组，坐标和文件列表使用空列表，数据块使用 ``b""``，文件属性使用空列表。每个响应对象拥有独立的 ``metadata`` 字典。

成功但没有数据的响应仍是有效响应，可以转换为空的 DataFrame 或 xarray 对象。错误响应不会伪装成空数据；调用 ``to_pandas()`` 或 ``to_xarray()`` 时会抛出结构化 CMADaaS 异常。高层入口仍先检查响应并按错误迁移 ADR 返回 ``MusicError`` 或抛出严格异常。

形状与坐标
----------

所有格点响应都要求纬度、经度坐标长度分别等于 ``lat_count``、``lon_count``，每个数据场元素数量等于二者乘积；风场的 U、V 分量分别校验。负维度、坐标长度不一致和数据长度不一致均在解码时抛出 ``ValueError``，不会由 NumPy ``reshape`` 产生无关错误。

缺少显式坐标时，根据起止值、步长和计数生成坐标；步长为零时兼容使用起止值的等距坐标。二维格点 DataArray 的维度固定为 ``("latitude", "longitude")``，坐标单位分别为 ``degrees_north`` 和 ``degrees_east``。

输出与 metadata
---------------

``Array2D.to_pandas()`` 保留 MUSIC 原始列名和原始字符串 dtype，并将请求时间等 metadata 放入 ``DataFrame.attrs``。标量格点转换为带原始要素名和 ``units`` 的 DataArray；矢量格点转换为包含 U/V 两个要素的 Dataset。格点输出保持原始数值 dtype，不静默把缺测值转换为 NaN。

客户端在响应 metadata 中记录 interface id，并从已知 MUSIC 参数复制时间、时间范围、预报时效、层次类型、层次值和集合成员等字段；请求/响应时间也来自 ``RequestInfo``。不复制任意参数，避免把密码或其他敏感字段带入输出对象。

后果
----

调用方可以直接对响应容器执行空值安全的长度和 shape 检查，并能区分“成功无数据”和“服务请求失败”。已有成功 DataFrame/xarray 的列名、维度、坐标、要素名、单位、dtype 和缺测值表示保持不变；新增的矢量 Dataset 转换和 metadata 为兼容的便利能力。
