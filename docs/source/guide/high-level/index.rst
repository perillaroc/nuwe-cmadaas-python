高层接口
========

高层函数按资料类别选择已登记的 MUSIC interface，并将响应转换为
``pandas``、``xarray`` 或下载文件路径。已登记组合见
:doc:`支持矩阵 <../../reference/support-matrix>`，完整签名见
:doc:`高层 API 参考 <../../reference/high-level>`。

客户端选择、YAML 查找规则与 ``client=`` 优先级见
:doc:`高层配置 <../configuration/high-level>`。
