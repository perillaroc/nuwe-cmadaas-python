公开 API 与兼容周期
===================

状态
----

已接受（2026-09-15）。

稳定入口
--------

``nuwe_cmadaas.music`` 是 MUSIC 兼容层稳定入口，提供
``CMADaaSClient``、响应对象、``MusicError`` 和结构化错误类型。
``nuwe_cmadaas.model`` 与 ``nuwe_cmadaas.obs`` 是高层业务入口，分别提供模式和
观测查询/下载函数。根包保留常用类型和高层函数的便捷导出；完整导出集合由各
模块的 ``__all__`` 冻结。未列入 ``__all__`` 的导入名称不构成公开 API 承诺。

类型支持
--------

包内包含 ``py.typed`` 标记。新增公共类型标注优先使用标准库、pandas、普通
mapping/list 和 pathlib 类型；内部 query/resolver 类型不从根包导出。当前阶段只
声明已实现的类型信息，不要求一次性为历史内部代码补齐完整静态检查。

兼容与弃用
----------

已有 ``callAPI_to_*`` 方法、参数名、MUSIC 原始参数文本和底层业务错误承载方式
继续保留。高层默认 ``strict=False``，旧调用仍返回 ``MusicError``；严格异常通过
显式 ``strict=True`` 启用。这个兼容路径至少保留到 ``1.0.0``，在此之前不会仅因
增加严格入口而删除旧返回路径。任何未来删除必须先在一个次版本中发出
``DeprecationWarning``，并在迁移指南和变更日志中说明替代调用。

新公开入口只做增量添加，不改变既有合法调用的返回类型、dtype 或 MUSIC interface
选择。高层未登记的组合继续建议使用底层兼容客户端。
