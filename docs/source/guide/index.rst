指南
====

从 :doc:`接口选择 <choosing-api>` 开始，再按业务场景进入高层或底层接口。
客户端配置说明集中在 :doc:`配置介绍 <configuration/index>`。
接口选择页以同一站点任务对照两层调用；
:doc:`高层概览 <high-level/index>` 列出 8 个业务入口，
:doc:`底层概览 <low-level/index>` 列出 9 个调用方法及返回形式。
结果数值化、单位/缺测与 attrs 见 :doc:`使用返回结果 <results>`；
默认 MusicError、strict 和本地异常见 :doc:`错误处理 <errors>`。
